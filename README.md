# Software Development Learning

An adaptive Codex skill for learning software development through practical lessons, progressive projects, and feedback.

It helps learners move from programming foundations to planning, building, debugging, testing, collaborating on, shipping, and maintaining software. The path adapts to the learner’s experience and goals instead of requiring a fixed stack or course sequence.

## Contents

- `SKILL.md` — tutor behavior, lesson flow, and project guidance
- `references/roadmap.md` — a broad coverage map from fundamentals through professional practice

## Install

Clone this repository into your Codex skills folder:

```powershell
git clone https://github.com/rahim6007/software-development-learning.git "$HOME/.codex/skills/software-development-learning"
```

Restart Codex if the skill does not appear immediately.

## Use

Invoke the skill with `$software-development-learning`, or ask Codex to help you learn programming, follow a software development roadmap, or build skills through a project.

## Customize

Edit `SKILL.md` to adjust the tutor’s teaching style. Edit `references/roadmap.md` to change the topic coverage. Keep the roadmap flexible so it can follow the learner’s goals and pace.
